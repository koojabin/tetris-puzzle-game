# Tetris Puzzle Game

테트리스 모양의 조각들을 정해진 틀 안에 끼워 맞추는 퍼즐 게임입니다.

## 게임 개요

- 한정된 테트리스 조각들을 제공
- 제공된 조각을 정해진 틀(보드) 안에 완벽하게 끼워 맞추면 클리어
- 광고 시청 시 조각 분해 기능 제공 (수익 모델)

## 기술 스택

- **Engine**: Unity
- **Platform**: Android / iOS

## 수익 모델

- 광고 시청 후 배치된 테트리스 조각 분해 가능

## 개발 환경 설정

1. Unity Hub에서 프로젝트 열기
2. 이 레포지토리를 clone 후 Unity로 열기

```bash
git clone https://github.com/koojabin/tetris-puzzle-game.git
```
